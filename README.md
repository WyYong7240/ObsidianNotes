## 重点主题

- Kubernetes：集群组件、调度器、Scheduling Framework、Informer、Operator、网络与监控。
- 云原生与 SRE：微服务监控、Trace 数据采集、异常检测、Chaos 工程和性能压测。
- Agent：Kubernetes 运维 Agent、工具调用、Agent 编排及生产环境中的安全边界思考。
- Go：语言基础、并发、工程实践和面试题整理。
- 求职准备：项目介绍、技术面试问题、算法题和不同公司的面试记录。

## 使用方式

1. 使用 Obsidian 打开本仓库目录。
2. 从 [`WorkPreparation/实习面试问题.md`](WorkPreparation/实习面试问题.md) 查看面试问题索引。
3. 从 [`WorkPreparation/简历项目准备.md`](简历项目准备.md) 查看项目讲解和追问准备。
4. 通过文档中的 Obsidian 双链跳转到对应主题的详细笔记。

## 笔记约定

- 技术主题按领域归档，面试记录按公司和面试轮次整理。
- 项目笔记优先记录背景、方案、实现、实验结果和可能的追问。
- 实验数据、部署步骤和环境信息以对应笔记中的实际记录为准。
- `.obsidian/` 保存本知识库的 Obsidian 配置；在其他设备打开前请注意插件和工作区配置差异。

本仓库是持续更新的个人学习与工作准备资料，部分内容来自实验、项目实践和面试复盘，不能替代官方文档或生产环境变更方案。
